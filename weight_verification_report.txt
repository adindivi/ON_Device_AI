════════════════════════════════════════════════════════════════════════

  ● 기본값: 15.0점    범위: 0.0 ~ 30.0점

  ● DTC 4계층 점수 분포 (dtcExactBoost = 15.0 기준):

      1등급 (완전 일치):       15.0점
      2등급 (끝자리 1자 오타): 12.8 ~ 13.5점
      3등급 (중간자리 오타):   10.5 ~ 12.0점
      4등급 (동일 계통):        8.3 ~  9.0점

  ● 분석:
    - 각 계층 간 최소 1.5점 이상 격차 유지
    - 완전 일치 시 +100점 프리미엄이 추가되어 절대적 1위 보장
    - 슬라이더 MAX(30.0)에서도 계층 간 비율이 동일하게 유지됨

  → 판정: 최적. 변경 불필요.

  ● 점수 산출 시나리오:

      기본값(1.0) × 매칭 6단어 = 6.0점 (상한)

    - 다단어 증상 입력 시 적절한 차등 부여

  → 판정: 최적. 변경 불필요.

  [4] 현장 추천 보너스 점수  —  ⚠️ 범위 수정
════════════════════════════════════════════════════════════════════════

  ● 기본값: 1.0점    범위: 0.0 ~ 5.0 → 0.0 ~ 3.0 (수정)
  ● 추천수 구간 배수: 1회(1.0x), 3회(3.3x), 10회(6.6x)

  ● 점수 산출 시나리오 (추천 10회 이상 문서):

      scale=1.0 → 1.0 × 6.6 =  6.6점
      scale=1.5 → 1.5 × 6.6 =  9.9점
      scale=2.0 → 2.0 × 6.6 = 13.2점
      scale=3.0 → 3.0 × 6.6 = 19.8점
      scale=5.0 → 5.0 × 6.6 = 33.0점

  ● 역전 시뮬레이션 (DTC 정확 일치 문서 vs 인기 무관 문서):

      ┌────────────────┬────────────────┬─────────────────┬──────────┐
      │ upvoteBonusScale│ DTC 문서 점수  │ 인기 문서 점수   │ 결과     │
      ├────────────────┼────────────────┼─────────────────┼──────────┤
      │ 0.0            │ 15.0점         │  7.0점          │ ✅ 정상  │
      │ 0.5            │ 15.0점         │ 10.3점          │ ✅ 정상  │
      │ 1.0 (기본)     │ 15.0점         │ 13.6점          │ ✅ 정상  │
      │ 1.5            │ 15.0점         │ 16.9점          │ ⚠ 역전! │
      │ 2.0            │ 15.0점         │ 20.2점          │ ⚠ 역전! │
      │ 3.0            │ 15.0점         │ 26.8점          │ ⚠ 역전! │
      │ 5.0            │ 15.0점         │ 40.0점          │ ⚠ 역전! │
      └────────────────┴────────────────┴─────────────────┴──────────┘

      * DTC 문서: DTC 정확 일치(15.0점), 추천 0회
      * 인기 문서: 부품+증상 일치(7.0점), 추천 10회

  ● 발견된 문제:
    upvoteBonusScale ≥ 1.5 부터, 추천수가 높은 무관한 문서가
    DTC 정확 일치 문서를 키워드 트랙에서 밀어내는 역전 발생.

  ● 조치:
    슬라이더 최대 범위를 5.0 → 3.0으로 축소.
    - 기본값(1.0)에서는 역전 없음 확인 (15.0 > 13.6)
    - MAX(3.0)에서 키워드 트랙 역전이 발생하더라도,
      DTC 계층 RRF 부스트(+10.0점)가 RRF 레벨에서 이를 보상
    - 사용자에게 "추천수 중시" 옵션은 유지하되,
      검색 정확도를 완전히 무너뜨리는 극단값(5.0)은 차단

  → 판정: 범위 0~3으로 수정 적용 완료.
